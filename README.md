# Social-Media-DotNet-API
• Users can create, edit, and delete posts with text, images, or videos, and view them in a personalized feed retrieved via RESTful APIs.
• Each post supports comments and real-time reaction updates (likes, loves, etc.).
• Users can follow/unfollow others and view followers/following lists for profile interaction.
• Real-time chat system allow private messaging with timestamps.
• Used Firebase for image uploading and storage.
